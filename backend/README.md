# Limt Trading Bot

بوت Telegram بسيط لعرض رسالة ترحيب عربية وزر يفتح Telegram Mini App.

## المتطلبات
- Node.js 18+
- توكن البوت من BotFather
- رابط GitHub Pages للـ Mini App

## التشغيل
1. انسخ `.env.example` إلى `.env`
2. ضع `BOT_TOKEN`
3. ضع `WEB_APP_URL`
4. شغّل:
   npm install
   npm start

## مهم
لا ترفع ملف `.env` إلى GitHub.
